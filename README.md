# Tp_algoritmos3
Juego de batalla de pokemones hecho en java.
Para poder ejecutar el juego se debe descargar la carpeta "PokemonAlgo3" e importar la carpeta al IDE después de eso ejecutar el programa desde la clase Main dando click a play, arriba a la derecha en el símbolo triángular, desde la aplicación IntewliJ IDEA.
